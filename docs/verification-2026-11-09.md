# 기능 검증 기록 — 2026-11-09

공개 main의 `2939d38611df34ab03d5a9dbdf299adc85934837`에서 시작해 아래 수정과 재검증을 수행했습니다. 실제 사용자 자료 대신 한글·공백 경로의 별도 검증 프로젝트와 6초 CFR 영상, 자막 3개, 분리 오디오 3개, 이미지, HTML을 사용했습니다.

## 발견하고 수정한 항목

- **FFmpeg 신버전 렌더 실패:** GitHub Windows CI의 FFmpeg 9에서 삭제된 `filter_script` 옵션으로 나레이션 동기화 렌더가 실패했습니다. 실행 파일의 지원 옵션을 확인해 기존 파일 입력 방식 또는 새 `-/filter:v` 방식을 선택합니다. 긴 필터를 명령줄에 직접 넣지 않아 Windows 길이 제한도 피합니다.
- **작성 중인 댓글 유실:** ‘수정 요청 추가’를 누르기 전 다른 작업물로 바꾸면 내용이 사라졌습니다. 작업물 전환·창 닫기 보호에 미추가 댓글도 포함했습니다. 전환 취소 후 초안 보존을 브라우저에서 재검증했습니다.
- **오디오 컨트롤 라벨:** 슬라이더와 음소거 버튼을 하나의 label 안에 넣은 구조를 분리하고 각 슬라이더에 명시적인 label을 연결했습니다. 포인터 및 접근성 기반 조작에서 음소거/해제와 실제 audio.volume을 대조했습니다.
- **검증 누락 방지:** 회귀 테스트 2개를 추가하고 CI에서 FFmpeg/ffprobe를 필수로 설치·확인하도록 변경했습니다. JavaScript 네 파일의 구문 검사도 포함했습니다.
- **Sites 검증 지침:** 배포 주소의 Range 응답과 실제 탐색, 이동/크기 변경 시 영상 내용의 즉시 반영, 연속 입력·저장 실패·충돌·재로딩을 별도로 확인하도록 보강했습니다. 지침 보강 자체가 모든 프로젝트용 Sites 어댑터의 구현·통과를 뜻하지 않습니다.
